# Reference

Detail moved out of `CLAUDE.md`, one file per area. If a file here and `CLAUDE.md` differ, `CLAUDE.md` wins.

- [Local development](local-development.md): Everything about running and testing the site on a Mac.
- [Member rules](member-rules.md): Domain rules, sign-in, schema notes and small site switches.
- [Suggestions and credits](suggestions-and-credits.md): How cards are made, ordered, charged and closed.
- [Matches and safety](matches-and-safety.md): Introductions, chat, blocks, reports, leaving.
- [Notifications and SMS](notifications-and-sms.md): Push, bell, SMS, WhatsApp codes and link routing.
- [Payments](payments.md): Stripe flow, checkout page, prices and conversion work. Failure reasons are in admin-panel.md.
- [Operations](operations.md): Server, cron, backups, Nginx, images and performance. Deploy steps are in `CLAUDE.md`.
- [Website UI](website-ui.md): Dashboard and landing page patterns.
- [Marketing and content](marketing-and-content.md): Polls, blog, SEO, analytics, live chat and the Pixel.
- [Admin panel](admin-panel.md): Admin pages, moderation, dashboards and reports.
- [Countries and the mobile app](countries-and-app.md): Multi-country rules and how the server serves the app. The app's own rules are in `naseebak_app/CLAUDE.md`.

Dated history is in [../project-history.md](../project-history.md). A few older notes still name sections of the old `CLAUDE.md`, such as Money or Analytics & Logs: look for them in these files by area.

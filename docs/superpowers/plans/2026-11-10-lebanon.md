# Lebanon (LB) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Lebanon (`LB`, `/lb`) as a third country, switched off by default, with WhatsApp sign-in codes via VerifyWay and a Lebanese-only «المذهب» profile field + partner preference; app 1.2.0 carries the sect and the WhatsApp wording.

**Architecture:** Country facts stay in `src/lib/countries/index.ts`; every `country === "SA" ? … : …` that means "not Jordan" becomes a per-country lookup so LB never inherits Jordanian text or currency. Sect is two additive Profile columns, gated to LB members on the server; scoring and «شروط أساسية» reuse the existing list-preference code.

**Tech Stack:** Next.js 16, Prisma 7, Zod v4 (`zod/v4`), Vitest; Flutter 3.41 (Riverpod).

**Spec:** `docs/superpowers/specs/2026-11-10-lebanon-design.md`
